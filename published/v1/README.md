# Происхождение light-набора v1

Это снимок **только 16 выбранных задач** исходной полной сборки AgentML Bench. Он хранится отдельно от активного evaluator.

- `catalog/groups.json` — четыре фиксированные группы и ссылка на parent commit/release.
- `catalog/effective_tasks.json` — исходные проверенные карточки выбранных задач.
- `audit/` — результаты аудита из большого набора.
- `calibration/local8/` — сохранённые параметры, предсказания и метрики исходного CatBoost.
- `environment/` — описание окружения той сборки и политики исключения встроенных sample datasets.

Новая установка создаёт свой runtime, проходит аудит и калибрует выбранные группы. Исторические результаты не копируются автоматически в `data/v1/calibration`. Совпадение названия профиля само по себе не доказывает совпадение окружения.

Проверки самой light-версии и запусков одной, двух и всех четырёх групп: `validation.json`. Текущий локальный отчёт light-сборки: `reports/`. Архив `calibration/` сохраняет происхождение эталона из parent benchmark; текущая калибровка при запуске хранится отдельно в `data/v1/calibration`.

Численные результаты эталона находятся в JSON/CSV архива, а не в корневом README. Оригинальные таблицы и разбиения выбранных задач включены в `data/v1/raw`. Агенту не монтируются ни архив, ни исходные размеченные таблицы, ни приватные ответы evaluator.
