# Проверка пригодности AgentML Bench Light v1

Итог: 16 задач подходят для единого табличного протокола в явно описанной постановке. Это не заявление, что любой датасет безупречен: ограничения каждой задачи ниже сохраняются. Семь первоначальных кандидатов заменены до первой публикации.

## Критерии и фактическая проверка

- Ровно 16 различных семейств; в каждой группе 2 регрессии, бинарная и многоклассовая классификации.
- Исходные таблицы совпадают с parent SHA-256; исходные разбиения не перестроены.
- Все опубликованные разбиения прошли проверку индексов, пересечений и соответствующих групповых ограничений.
- В Standard нет тестовых классов, отсутствующих в train; каждый класс задачи представлен в test.
- Ни у одной задачи нет точной копии target среди признаков. Полные ответы не попадают в test.csv.
- Доля test-профилей, совпавших по всем входным полям с train, ограничена 5% при выборе. Это порог данной подборки, а не универсальная граница утечки. Измеренные доли приведены ниже.
- Эталон CatBoost успешно откалиброван на всех 16 случаях в local8; нет замены другим baseline.
- На Standard эталон сильнее константы, оценённой только по train: среднего для регрессии и частого класса для классификации. Это критерий данной подборки, а не доказательство превосходства на всех возможных splits.
- Момент доступности полей, исходная шкала target и смысл групп описаны в task.md/task.json агента.

## Интерпретация качества

Dermatology — небольшой лёгкий случай с высоким качеством эталона и малым запасом нормировки. Одна ошибка может сильно менять его нормированный балл. Это задача для проверки базовой корректности, а не самостоятельный тест общего интеллекта. Не делайте выводы по одному датасету или одному запуску.

Промежуточный кандидат Musk также исключён: на Standard фиксированный CatBoost уступал train-only majority predictor, что делало нормированный score слишком лёгким для константного ответа. Вместо него включён Polish Companies Bankruptcy, где эталон сильнее этой простой проверки. Это фильтр набора по одному стандартному разбиению, а не рейтинг сложности алгоритмов.

Mice Protein содержит повторные измерения мышей: независимый объект — мышь. Составные поля класса удалены куратором, разбиения групповые. [UCI Mice](https://archive.ics.uci.edu/dataset/342/mice+protein+expression).

Student Dropout использует показатели после первого и второго семестров. Нельзя интерпретировать результат как прогноз при поступлении. [UCI Student Dropout](https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success).

В light-v1 нет временного теста. Неудачные временные кандидаты не включены ради искусственного покрытия. Для оценки временного сдвига используйте соответствующие задачи большого benchmark.

Машиночитаемые результаты, распределения классов, группа train/test и сравнение с train-only средним/частым классом: [suitability.json](suitability.json), [suitability.csv](suitability.csv). Публичные данные могут быть запомнены LLM; изоляция файлов не устраняет загрязнение предобучения.
